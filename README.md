# Aashish-Enterprise

> **आशिष एंटरप्राइजेस (Ashish Enterprises)** — महाराष्ट्र आधारित कृषी उत्पन्न बाजार समिती (APMC) परवानाधारक शेतमाल व्यापार व आडत व्यवसाय डिजिटल प्लॅटफॉर्म.

---

## 🌾 प्रकल्प परिचय (Project Overview)

**Ashish Enterprises** हा हिंगोली, बावसमत, नांदेड, लातूर, आणि परभणी येथील कृषी उत्पन्न बाजार समित्यांमध्ये कार्यरत असलेला शेतमाल व्यापार व आडत व्यवसाय आहे. हा आधुनिक व मराठी-प्रथम (Marathi-First, Mobile-First) वेब प्लॅटफॉर्म शेतकऱ्यांना थेट शेतमाल विक्री नोंदणी, विनंती ट्रॅकिंग, आणि प्रशासकीय कर्मचाऱ्यांना सर्वसमावेशक डॅशबोर्ड उपलब्ध करून देतो.

---

## 🚀 मुख्य वैशिष्ट्ये (Key Features)

### 👨‍🌾 शेतकरी व सार्वजनिक पोर्टल (Public Farmer Portal):
- **मराठी-प्रथम इंटरफेस:** सर्वसामान्य शेतकऱ्यांसाठी सहज समजणारी देवनागरी मराठी रचना.
- **शेतमाल विक्री नोंदणी (`/sell-produce`):** शेतकरी तपशील, पिकाचा प्रकार, प्रमाण (किलो/क्विंटल/टन), मालाची प्रत आणि फोटो अपलोड.
- **पारदर्शक ट्रॅकिंग (`/track-request`):** ८-टप्प्यांची मराठी प्रगती टाइमलाइन (विनंती प्राप्त &rarr; संपर्क &rarr; तपासणी &rarr; व्यवहार निश्चित &rarr; पेमेंट &rarr; पूर्ण).
- **कठोर गोपनीयता (Privacy Barrier):** सार्वजनिक ट्रॅकिंगवर शेतकऱ्याचे नाव अंशतः मास्क केले जाते (उदा. `ज्ञा**** पा****`) आणि अंतर्गत व्यापारी/आर्थिक नोंदी सुरक्षित ठेवल्या जातात.
- **१२+ प्रमुख शेतमाल यादी (`/commodities`):** हळद (काडी, गोळा, तुकडी, ताळक्या), कापूस, सोयाबीन, गहू, ज्वारी, मूग, हरभरा इ.

### 🛡️ ॲडमीन व्यवस्थापन डॅशबोर्ड (Admin Management Portal):
- **डॅशबोर्ड (`/admin/dashboard`):** शेतमाल विनंत्या, चालू व्यवहार आणि प्रलंबित पेमेंट्सचे सांख्यिकी विश्लेषण.
- **विनंत्या व्यवस्थापन (`/admin/requests`):** शेतकऱ्यांच्या विनंत्या तपासणे, थेट कॉल/WhatsApp संपर्क आणि स्थिती बदल.
- **व्यवहार नोंदवही (`/admin/transactions`):** व्यवहार दर, एकूण रक्कम, कमिशन आणि APMC सेस कपात हिशोब.
- **पेमेंट पावत्या (`/admin/payments`):** ॲडव्हान्स, वजन पावतीनंतर आणि अंतिम सेटलमेंट पावत्या.
- **खरेदीदार निर्देशिका (`/admin/buyers`):** घाऊक खरेदीदार, दाल मिल्स, जिनिंग मिल्स नेटवर्क.

## 🛠️ तंत्रज्ञान (Technology Stack)

- **Framework:** Next.js 16 (App Router)
- **Library:** React 19
- **Language:** TypeScript (Strict Mode)
- **Styling:** Tailwind CSS v4 & PostCSS
- **Forms & Validation:** React Hook Form + Zod v4 (Marathi error messaging)
- **Icons:** Lucide React
- **Architecture:** Decoupled In-Memory Mock Service Layer (`src/lib/mock-service.ts`)

## 💻 स्थानिक पातळीवर चालवण्यासाठी (Local Development)

### १. प्रोजेक्ट क्लोन करा:
```bash
git clone https://github.com/rohanumbarepatil/Aashish-Enterprise.git
cd Aashish-Enterprise
```

### २. डिपेंडन्सीज इन्स्टॉल करा:
```bash
npm install
```

### ३. डेव्हलपमेंट सर्व्हर सुरू करा:
```bash
npm run dev
```

ब्राउझरमध्ये उघडा: [http://localhost:3002](http://localhost:3002)
